# Revision Drills

Use exactly one runtime action: `PRESERVE / MIN_EDIT / REVISE / HOLD-INSUFFICIENT_EVIDENCE`.

- Smallest useful edit wins when the intended effect survives.
- Structural blockers outrank local polish.
- A targeted pass answers one primary diagnostic question; cross-domain edits require causal necessity.
- Preserve intentional fragment, repetition, dialect, register shift, graded revelation, polyphony, motif ambiguity, and historical/source uncertainty when functional.
- After every edit, check meaning, evidence status, access, causality, clue, voice/register, rhythm, information architecture, and intended effect as relevant.
- Reject a revision that solves one problem by creating a new material failure.
- Stop when no material failure remains. Do not add vividness, metaphors, synonyms, or punctuation changes merely because another pass is available.
