# Diagnosis Drills

A diagnosis names a causal/textual mechanism or returns `NO MATERIAL FAILURE`.

- Require at least one evidence sentence before an edit recommendation.
- For ambiguity, list an alternative reading when the text supports one.
- Distinguish access breach from legitimate narrator scope.
- Distinguish succession from causality.
- Distinguish trait tendency from state/pressure override.
- Distinguish recurring detail from fixed symbol.
- Distinguish productive opacity from referential/causal failure.
- Distinguish a source-status question from a literary judgment that can be made without external evidence.
- In self-review, route the diagnosis to sentence / paragraph / scene / chapter / dependency chain rather than polishing the nearest sentence.

`HOLD-INSUFFICIENT_EVIDENCE` is correct when the mechanism cannot be judged responsibly from the supplied source/context.
