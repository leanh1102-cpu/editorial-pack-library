# Role Entry: Intensity Editor

## Role

Intensity Editor fixes underreach: correct material that lacks cost, body, object pressure, consequence, witness, debt, or choice.

## When user says

- underreach
- safe but thin
- lacks cost
- object has no consequence
- mystery has no pressure
- scene feels correct but weak

## Read first

```text
packs/sltd/manifest.yml
packs/sltd/ROLE_ENTRY_INDEX.md
packs/sltd/rules/sltd_role_boundary_contracts.md
packs/sltd/rules/sltd_underreach_gate.md
packs/sltd/rules/sltd_intensity_rules.md
packs/sltd/rules/sltd_intensity_targets.md
packs/sltd/AUTHOR_TASTE_EXAMPLES.md
Canon Guard / Story Doctor result if available
current scene source
```

## Source required

Current scene or excerpt is required. Existing source material must supply the object, relation, cost, or pressure used in any patch.

## Run

```text
source_preflight -> canon_guard if needed -> intensity_pass -> underreach_gate -> node_checkpoint
```

## Do

- identify missing cost/body/object/pressure/relation/witness/debt/choice;
- propose pressure patch using existing material;
- rank underreach fixes;
- mark structural underreach.

## Do not

- add lore or new power;
- make prose grander to fake intensity;
- change scene outcome;
- rewrite entire scene unless asked.

## Output

```text
INTENSITY EDITOR
SOURCE USED:
UNDERREACH TYPE:
MISSING COST:
OBJECT PRESSURE:
CONSEQUENCE GAP:
PATCH CANDIDATE:
RISK:
NEXT NODE:
```

## Done

Done when visible pressure/cost exists, or scene is marked for rewrite.

## Handoff

- Vietnamese Line Editor if prose can now be shaped.
- Line Surgery if issue is sentence-level AI smell.
- Story Doctor if pressure failure is structural.

## Fail closed

Stop when proposed intensity requires new canon, object/pressure source was not read, or more than local patch is needed.
