Use this prompt before prose work when act, arc, hồi, chapter, scene, detailed outline, Chapter Card, Scene Packet, or borderbound is in scope.

This prompt does not authorize new canon, new plot, new scenes, new outline content, or source writes unless the user explicitly asks for a design/write action.

## Rules

- Do not write or edit prose from summary, chat memory, or taste alone.
- Do not start prose when current Story Outline / Chapter by Chapter Outline is required but unread.
- Do not start prose when Chapter Card or Scene Packet is missing required fields for the requested scope.
- Do not let protagonist gain, supernatural residue, lore, or clue chain float outside the chapter spine.
- If outline is thin or contradictory, return OUTLINE_REPAIR_REQUIRED instead of compensating with prose.
- If the user only asks for diagnosis, produce a blocker map and Notion update candidate, not a source write.
- End with NEXT NODE.
