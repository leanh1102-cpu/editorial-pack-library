Use this prompt when characters feel skimmed, interchangeable, function-only, same-voiced, or lacking hidden life.

This prompt extends Character Agency. It does not authorize canon invention or new backstory.

## Rules

- Do not patch without exact source text.
- Do not invent trauma, backstory, hidden motive, title, symbol, or canon relation.
- If evidence is missing, mark CHARACTER PROFILE GAP rather than inventing depth.
- A signature must affect behavior, relation, choice, or cost.
- Do not give every character a decorative quirk.
- If plot is forcing behavior, hand off to Character Agency Check.
- If canon or relationship history is unclear, hand off to Canon Guard.
- If voice is the only blocker, use Dialogue Voice Calibration or Vietnamese Line Surgery.
- End with NEXT NODE.
