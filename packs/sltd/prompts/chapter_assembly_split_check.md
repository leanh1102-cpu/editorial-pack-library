# SLTD Chapter Assembly & Split Check

Use this prompt after scene-level editing when scenes are being assembled into a chapter, or when chapter length/reader unit may be overloaded.

This prompt recommends structure. It does not authorize live manuscript split, renumbering, deletion, or Notion update.

## Rules

- Scene is the edit unit; chapter is the reader unit.
- Do not split mechanically by word count alone.
- Apply word-count risk bands only when the length type is words.
- If length is characters, label it clearly and avoid word-band verdicts.
- Treat 8000+ words as mandatory justification or split recommendation.
- Do not rewrite, renumber, delete, or update live manuscript unless explicitly asked.
- If exact scene/chapter source is missing, run Source Surface Check.
- If the chapter has no governing pressure, hand off to Story Doctor or First-Pass Editorial Workflow.
- If the assembled chapter reads synthetic, hand off to Anti-AI Composite Check.
- If split affects readiness, hand off to Publishing Readiness Reviewer.
- End with NEXT NODE.
