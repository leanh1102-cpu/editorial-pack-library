# SLTD Scene Composition & Component Balance Check

Use this prompt when scene component mix is in scope: dialogue, action/blocking, inner thought, setting/living world, object/clue, sensory/body, silence/pause, summary/transition, and aftershock.

This prompt uses soft diagnostic bands. It must not turn prose into a formula.

## Rules

- Do not patch without exact source text.
- Do not apply percentages mechanically.
- Percentages are diagnostic bands, not writing formulas.
- Composition follows scene function.
- Do not add components just to fill a band.
- A component is valid only if it changes pressure, relation, information, cost, movement, or reader breath.
- If scene function is unclear, hand off to First-Pass Editorial Workflow or Scene-First Prose Judgment.
- If fake balance is caused by missing beat escalation, hand off to Narrative Beat Escalation & Aftershock Check.
- If setting/living world is decorative, hand off to Living World & Community Motion Check.
- End with NEXT NODE.
