# SLTD Author Voice Fingerprint Check

Use this prompt when the task asks to decode, learn, compare, or preserve author voice.

This is a source-backed style extraction pass, not a memory guess and not a ghostwriter draft by itself.

## Read first

```text
manifest.yml
AUTHOR_WORKING_PROFILE.md
AUTHOR_TASTE_EXAMPLES.md
rules/sltd_source_preflight.md
rules/sltd_source_fidelity_anti_compression.md
rules/sltd_author_voice_fingerprint_ghostwriter_discipline.md
rules/sltd_context_capsule_lore_retrieval_discipline.md if current source, hidden canon, POV knowledge, source-status separation, object/location/body/debt state, relationship memory, or long-range continuity is in scope
rules/sltd_character_voice_dialogue_relationship_location_gate.md if dialogue, character voice, relationship, or staging is being compared
rules/sltd_vietnamese_senior_editor_surface_pass_integrity_gate.md if exact Vietnamese surface is in scope
```

## Source requirement

Use only approved or explicitly provided author samples.

If samples are missing, unclear, legacy-only, or not named as current/approved, return:

```text
AUTHOR_SAMPLE_MISSING / EVIDENCE MISSING
```

Do not build an author profile from chat memory alone.

## Rules

- Separate fact, inference, and recommendation when sample coverage is thin.
- Learn how the author thinks a scene, not only favorite wording.
- Do not turn style into repeated templates.
- Do not add canon or infer personal facts from prose samples.
- Do not override character voice with author voice.
- Do not call readiness, Human Chapter Pass, or Publication Lock.
