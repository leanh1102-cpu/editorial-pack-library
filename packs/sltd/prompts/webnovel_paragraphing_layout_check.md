## Rules

- Exact source text is required for patching.
- One-sentence paragraphs are emphasis tools, not the default style.
- Paragraphs should avoid both choppy fragments and wall text.
- Line breaks should follow structural shifts.
- Rapid dialogue should stay readable without fragmenting every small body beat.
- One-line aftershock should be earned by a real turn.
- If cadence is flat, hand off to Dynamic Range Check.
- If prose itself is weak beneath layout, hand off to Scene-First Prose Judgment or First-Pass Editorial Workflow.
- End with NEXT NODE.
