# SLTD Dynamic Range Check

Use this prompt when AI restraint may have flattened scene cadence, scene turn, dialogue force, payoff, or reader pull.

This prompt does not authorize canon invention, source overwrite, or melodrama.


## Rules

- Match intensity to scene function.
- Do not make every scene quiet.
- Do not make every scene high-force.
- Keep unrevealed lore quiet while allowing object, relation, cost, silence, or choice to gain pressure.
- If exact source text is missing, do not patch. Run source surface check.
- If story function is unclear, hand off to Story Doctor.
- If scene is clean but not sharp, hand off to Intensity Editor.
- If dialogue is defanged, hand off to Vietnamese Line Editor or Line Surgery.
- End with NEXT NODE.
