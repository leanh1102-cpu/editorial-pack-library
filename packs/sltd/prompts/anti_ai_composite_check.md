# SLTD Anti-AI Composite Check

Use this prompt when a scene or chapter passes several checks but still reads as arranged, synthetic, over-polished, or AI-made.

## Read first

```text
manifest.yml
rules/sltd_source_fidelity_anti_compression.md
rules/sltd_character_agency_anti_ooc_gate.md
rules/sltd_dynamic_range_cadence_gate.md
rules/sltd_anti_ai_composite_failure_gate.md
rules/sltd_role_boundary_contracts.md
AUTHOR_TASTE_EXAMPLES.md
```

## Patch output when exact source is available

```text

```

## Rules

- Do not patch without exact source text.
- Do not add texture to hide synthetic structure.
- Do not use green sub-passes as readiness proof.
- Choose one governing scene pressure before recommending repair.
- Hand off to Character Agency Check when character agency fails.
- Hand off to Dynamic Range Check when cadence or pressure fails.
- Hand off to Source Surface Check when source surface is missing.
- Hand off to Publishing Readiness Reviewer when readiness conflict appears.
- End with NEXT NODE.
