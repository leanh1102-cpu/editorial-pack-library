# SLTD Author-Aligned Ghostwriter Draft

Use this prompt when the user asks for prose drafted in the author's voice, or when a rewrite has source/canon/scene permission and needs author-aligned drafting.

This is not autonomous authorship. It is bounded drafting under source, canon, POV, scene function, and author fingerprint.

## Read first

```text
manifest.yml
AUTHOR_WORKING_PROFILE.md
AUTHOR_TASTE_EXAMPLES.md
rules/sltd_source_preflight.md
rules/sltd_source_fidelity_anti_compression.md
rules/sltd_context_capsule_lore_retrieval_discipline.md if current source, hidden canon, POV knowledge, source-status separation, object/location/body/debt state, relationship memory, or long-range continuity is in scope
rules/sltd_structural_spine_outline_preprose_borderbound_gate.md if scene function or prose permission is unclear
rules/sltd_tracking_logic_ledger_traceability_gate.md if state, object, debt, residue, thread, or downstream risk is affected
rules/sltd_character_voice_dialogue_relationship_location_gate.md if dialogue, character voice, relationship, silence, presence, or staging is in scope
rules/sltd_vietnamese_senior_editor_surface_pass_integrity_gate.md
rules/sltd_author_voice_fingerprint_ghostwriter_discipline.md
prompts/author_voice_fingerprint_check.md if no author fingerprint has been produced for this task
```

## Source requirement

Do not draft from chat memory alone.

Before drafting, confirm:

```text
source surface or current scene packet has been read
context capsule is clear when required
scene question is known
must show is known
must not reveal is known
reader effect is known
author fingerprint or approved author taste source is available
```

If not, return:

```text
DRAFT_PERMISSION_BLOCKED
```

## Drafting rules

- Draft only the requested scope.
- Preserve canon, POV, reveal lock, scene function, and reader effect.
- Use author rhythm to shape prose; do not overwrite character voice.
- Use objects, body pressure, silence, and household/world pressure already allowed by source.
- Do not add lore, new object, new relationship, new scene beat, new solution, or new payoff.
- Do not write slogan endings or clean thesis endings.
- Do not call Human Chapter Pass, readiness, or Publication Lock.
- Hand off to Human Surface Polish after drafting when the passage still reads synthetic, falsely smooth, or same-voiced.
