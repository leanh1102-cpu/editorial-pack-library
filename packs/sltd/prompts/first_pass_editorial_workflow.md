# SLTD First-Pass Editorial Workflow

Use this prompt for the first serious edit of a scene or excerpt before targeted gates are applied.

This is not a readiness check. It is a scene-first editing workflow.

## Read first

```text
manifest.yml
rules/sltd_source_fidelity_anti_compression.md
rules/sltd_first_pass_editorial_workflow.md
rules/sltd_scene_first_prose_judgment_gate.md
rules/sltd_role_boundary_contracts.md
AUTHOR_TASTE_EXAMPLES.md
```

## Rules

- Do not patch without exact source text.
- Start with scene pressure, not checklist compliance.
- Choose the earliest failing layer before line polishing.
- Use one main edit strategy for the first pass.
- Read the draft once as natural Vietnamese prose before naming gate results.
- Run only the targeted gate that matches the remaining blocker.
- If governing pressure is missing, stop before patch and hand off to Story Doctor or Scene-First Prose Judgment.
- End with NEXT NODE.
