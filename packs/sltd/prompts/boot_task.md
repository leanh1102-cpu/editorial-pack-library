# SLTD Boot Task

Use this prompt at the start of any SLTD task.

## Read first

1. `packs/sltd/manifest.yml`
2. `packs/sltd/PACK.md`
3. `packs/sltd/AGENT_IDENTITY.md`
4. `packs/sltd/AUTHOR_WORKING_PROFILE.md`
5. `packs/sltd/rules/sltd_memory_boundaries.md`
6. `packs/sltd/rules/sltd_boot_sequence.md`
7. `packs/sltd/rules/sltd_source_preflight.md`

## Output

```text
AGENT ROLE:
SOURCE USED:
SCOPE:
CURRENT SOURCE LAYER:
LOCK STATUS:
TASK SKILL:
STOP CONDITION CHECK:
```

After this, choose the task-specific prompt.

If source or scope is unclear, stop before giving an editorial verdict.
