# SLTD Scene Transition / Skiptime / Event Cluster Check

Use this prompt when scene transitions, seam continuity, sensory or symbolic bridges, skiptime, process trace, or event-cluster continuity is in scope.

This prompt audits continuity across cuts. It does not authorize new scenes, events, clues, folklore, or payoff.

## Rules

- Do not patch without exact source text.
- Do not invent new scenes, events, witnesses, clues, folklore, payoff, or canon continuity.
- A transition must carry pressure, information, cost, time, POV access, material state, or aftershock.
- Skiptime must leave process trace.
- Sensory or symbolic bridge is valid only if it changes continuity, not just mood.
- Event cluster must have start, development, result, and aftershock.
- Do not change POV access or timeline to smooth a seam.
- If event order or POV access is unclear, hand off to Timeline / POV / Foreshadowing / Folklore Check.
- If chapter flow is affected, hand off to Chapter Assembly & Split Check.
- End with NEXT NODE.
