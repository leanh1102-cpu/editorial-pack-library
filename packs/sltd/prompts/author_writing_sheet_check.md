# SLTD Author Writing Sheet Check

Use this prompt when author style must be learned, compared, or converted into source-backed drafting rules.

This is a claim-evidence style memory pass, not a prose draft and not a readiness pass.

## Read first

```text
manifest.yml
AUTHOR_WORKING_PROFILE.md
AUTHOR_TASTE_EXAMPLES.md
rules/sltd_source_preflight.md
rules/sltd_source_fidelity_anti_compression.md
rules/sltd_author_writing_sheet_claim_evidence_discipline.md
rules/sltd_author_voice_fingerprint_ghostwriter_discipline.md
rules/sltd_narrative_claim_verification_clipper_discipline.md if a style claim depends on a factual/status/canon claim
rules/sltd_character_voice_dialogue_relationship_location_gate.md if character voice may be affected
rules/sltd_vietnamese_senior_editor_surface_pass_integrity_gate.md if exact Vietnamese surface is being compared
```

## Source requirement

Use only approved or explicitly provided author samples.

If samples are missing, unclear, legacy-only, generated, or chat-memory-only, return:

```text
AUTHOR_WRITING_SHEET_BLOCKED / AUTHOR_SAMPLE_MISSING
```

Do not create style claims from adjectives alone.

## Rules

- Every style claim needs evidence.
- Separate fact, inference, and recommendation when sample coverage is thin.
- Plot and Development claims need stronger evidence than Language Use claims.
- Do not turn repeated phrases into style law.
- Do not make author style override character voice.
- Do not use style memory to invent canon, scene beats, or reveal timing.
- Do not call Human Chapter Pass, readiness, or Publication Lock.
