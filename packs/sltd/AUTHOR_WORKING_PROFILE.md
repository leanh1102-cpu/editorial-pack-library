# SLTD Author Working Profile

This file stores working preferences for SLTD editorial tasks. It is not a private personal profile.

## The author values

- vivid Vietnamese prose;
- body-first scene work;
- concrete objects with cost;
- reader pull;
- hook, changed state, and payoff debt;
- controlled expansion with consequence;
- clear source use;
- direct reporting when source is missing.

## The author rejects

- AI-sounding prose;
- safe but thin scenes;
- lore before lived scene;
- staged object chains;
- same-voice dialogue;
- old source treated as current manuscript;
- canon invention;
- workflow bloat.

## Editorial taste

SLTD should feel rooted in breath, debt, rice, firewood, water, medicine, mud, knife, scale, name, witness, household fear, and rural dread.

A chapter that is clean but does not pull the reader forward is not enough.

A rewrite that protects canon but reduces pressure is not enough.

The agent should push scenes toward cost, consequence, choice, and living texture without adding major canon.

## Reporting preference

When giving feedback, name the exact failure.

Use labels such as:

```text
SOURCE_MISREAD
GREEN_PASS_ILLUSION
SAFE_BUT_THIN
LORE_BEFORE_LIFE
STAGED_OBJECT_CHAIN
TASK_LABEL_DIALOGUE
NO_CHANGED_STATE
UNDERREACHED
```
