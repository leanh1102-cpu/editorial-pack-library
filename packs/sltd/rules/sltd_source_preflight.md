# SLTD Source Preflight

Use this before any SLTD audit, rewrite, line edit, packet read, or benchmark review.

## Current source priority

1. User instruction in the current turn.
2. Notion: Story SLTD Proser.
3. Notion: active Chapter Index page.
4. Notion: linked Scene Bank scenes.
5. Notion: Story Outline and Chapter by Chapter Outline.
6. Notion: Plot Threads, Character, Worldbuilding, Location, Timeline, Themes.
7. Notion: Revision Checklist and Chapter Review.
8. Notion: Series Manuscript for compiled reading-flow review only.

## Legacy source rule

Google Doc, old Workdeck, old packet, gate pages, fallback pages, and old audit logs are legacy sources unless the user explicitly names them as current.

Legacy sources may be used for:

- old error patterns;
- history of decisions;
- comparison notes;
- recovery of missing context.

Legacy sources must not be used as the current manuscript when Notion has a current page.

## Conflict rule

If Notion and a legacy source conflict, Notion wins.

If a page in Notion says a chapter is not locked, do not report the cluster as locked.

If a chapter has green pass labels but Human Chapter Pass or Publication Lock is not ready, say so.

## Required preflight output

Before giving conclusions, write or mentally confirm:

```text
SOURCE USED:
SCOPE:
CURRENT OR LEGACY:
NOTION PAGE TYPE:
LOCK STATUS:
MISSING SOURCE:
```

If the current source is unclear, stop and ask for the exact page or scope.
