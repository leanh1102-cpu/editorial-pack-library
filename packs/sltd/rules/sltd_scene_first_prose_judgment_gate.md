# SLTD Scene-First Prose Judgment Gate

This gate prevents the AI from writing or editing by checklist compliance before judging the scene as lived prose.

It keeps the system as an editorial safety net, not a mold for the prose.

## Core rule

Scene first. Checklist after.

```text
SCENE JUDGMENT = read the scene as lived Vietnamese prose before applying gates
CHECKLIST = later verification, not the writing method
PROSE LIFE = pressure, relation, object, body, silence, and sentence rhythm working as one lived movement
```

Do not begin by satisfying gates.

Begin by finding the living pressure of the scene.

## Use when

- the prose reads like the AI is proving it followed rules;
- a rewrite satisfies scene fields but feels like homework;
- body beats, objects, silence, cost, and dialogue appear as required items;
- the output follows gates before understanding the scene;
- the scene has correct materials but no single governing pressure;
- prose is Vietnamese-correct but editorially dead;
- the user says checklist-first, trả bài, gò theo hệ thống, ép khung, or not natural Vietnamese prose.

## Authority

This gate sits below:

```text
current user instruction
current Notion source or user-provided source packet
source fidelity gate
canon guard
evidence discipline
role boundary contracts
```

It runs before anti-AI composite, character agency, dynamic range, and line surgery when the issue is checklist-first execution.

It must not add canon, change locked outcome, or override exact source surface.

## Scene-first sequence

Before repair, identify:

```text
LIVING PRESSURE:
WHO IS UNDER PRESSURE:
WHAT PRACTICAL THING IS HAPPENING:
WHAT THE SCENE MUST NOT SAY YET:
WHAT THE SCENE MUST MAKE FELT:
ONE GOVERNING PRESSURE:
```

If `ONE GOVERNING PRESSURE` is missing, do not line edit. Hand off to Story Doctor or Anti-AI Composite Check.

## Prose alive vs checklist satisfied

Separate:

```text
CHECKLIST SATISFIED:
- has object
- has body beat
- has silence
- has cost
- has dialogue pressure

PROSE ALIVE:
- object changes action
- body slows, exposes, or costs someone
- silence changes relation
- cost leaves trace after the scene
- dialogue resists rather than reports
```

A scene is not ready because the checklist is satisfied.

## Showing-the-work risk

Flag when prose exposes editorial machinery:

```text
RULE_PERFORMANCE
CHECKLIST_VISIBLE
SCENE_CARD_LANGUAGE
OBJECT_INSERTED_FOR_GATE
BODY_BEAT_AS_TOKEN
SILENCE_AS_TOKEN
COST_AS_TOKEN
AFTERSHOCK_AS_SLOT
VOICE_DIFFERENCE_PERFORMED
PROSE_TRABAI
```

## Editorial order

Use this order for prose work:

```text
1. Read exact source surface.
2. Find living pressure.
3. Judge scene movement as Vietnamese prose.
4. Identify what feels fake, dead, over-managed, or over-compliant.
5. Only then run specific gates for missed risks.
6. Patch minimally or recommend rewrite when structure is false.
```

Do not run all gates as a ritual.

Use the smallest gate that answers the problem.

## Repair principles

Do:

- reduce visible rule performance;
- choose one governing pressure;
- remove body/object/silence beats that do not change action;
- let Vietnamese sentence rhythm follow pressure instead of template;
- keep scene mess, interruption, and partial speech when they make the prose more lived;
- use checklist only to catch missed blockers after the scene judgment.

Do not:

- add more required-looking details;
- make prose prove it has objects, body, silence, cost, or voice;
- flatten Vietnamese rhythm into tidy explanation;
- polish away useful roughness;
- line edit before source surface and scene pressure are clear;
- treat gate compliance as publication readiness.

## Patch rule

If exact source text is available:

```text
OLD:
WHY IT READS LIKE CHECKLIST:
NEW:
WHAT RULE-PERFORMANCE WAS REMOVED:
WHAT NOW DRIVES THE PROSE:
RISK:
```

If exact source text is missing, do not patch. Run Source Surface Check.

## Handoff

If no governing pressure is found, hand off to Story Doctor or Anti-AI Composite Check.

If character pressure is false, hand off to Character Agency Check.

If cadence is flat, hand off to Dynamic Range Check.

If line rhythm is the only blocker after scene judgment, hand off to Line Surgery.
