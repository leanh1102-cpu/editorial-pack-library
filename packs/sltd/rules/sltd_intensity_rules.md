# SLTD Intensity Rules

Purpose: reduce underreach. The pack may add near-scene detail when it has source basis, consequence, and rollback risk.

Allowed:
- add small scene detail;
- add local consequence;
- sharpen cost;
- sharpen choice;
- clarify promise already seeded.

Blocked:
- new named character;
- new lore;
- new power;
- new faction;
- changed locked outcome;
- copied structure from another novel.

Ledger:

```text
SOURCE BASIS:
EXPANSION:
CONSEQUENCE:
ROLLBACK RISK:
```
