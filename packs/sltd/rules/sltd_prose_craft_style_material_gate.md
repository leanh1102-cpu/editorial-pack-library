# SLTD Prose Craft, Genre Style & Material Calibration Gate

This gate turns SLTD prose craft, genre technique, style, voice, and material choices into usable calibration moves.

It is a calibration layer, not a style imitation layer.

## Core rule

Craft samples are calibration, not voice to imitate.

```text
CRAFT MOVE = a conditional editing / writing technique used for a scene function
STYLE CALIBRATION = a way to choose register, rhythm, material, and degree without copying a sample
MATERIAL LAYER = the concrete life-substance that carries pressure: body, work, object, place, weather, debt, animal, tool, food, medicine, road, rumor, taboo
GENRE FUNCTION = what the move serves: mystery, dread, survival, cost, pursuit, reveal, concealment, consequence, promise/payoff
```

Do not copy sample sentence shape.

Do not add craft moves to show craft.

Use a move only when it changes pressure, relation, information, cost, movement, reader breath, or genre promise.

## Use when

- a task asks about writing technique, editing technique, genre style, prose style, voice, material, or craft samples;
- prose follows rules but still lacks concrete technique;
- the agent needs a reusable move rather than a one-off patch;
- a passage needs calibration against AI-polished prose, translated xianxia prose, modern-flat prose, or checklist prose;
- a scene needs a specific move: grounding after dialogue, object pressure, delayed answer, offscreen pressure return, body-cost, rumor mutation, summary compression, or aftershock residue;
- the user asks for mẫu thao tác, kỹ thuật viết, chất liệu, văn phong, giọng, phong cách, or thể loại.

## Authority

This gate sits below:

```text
current user instruction
current Notion source or user-provided source packet
source fidelity gate
canon guard
evidence discipline
role boundary contracts
```

It must not invent canon, copy another author, imitate benchmark novels, create new lore, or rewrite live source without permission.

Samples are not canon and not current manuscript.

## Craft families

### Prose technique

Use for scene entry, grounding, transition, summary, concrete pressure, scene-native image, and aftershock.

Common moves:

```text
enter through object / body / task
return to ground after dialogue
replace explanation with action or refusal
hold mystery behind concrete pressure
compress non-pressure movement
end with residue instead of slogan
```

### Dialogue technique

Use for evasion, concealment, voice difference, age/work/fear/social relation, wrong hearing, interruption, and half-truth.

Common moves:

```text
one character evades
one character asks the wrong question
one character hears only half a sentence
one character changes topic because the room is unsafe
body or object returns after speech
```

### Character technique

Use for voice signature, body signature, habit under pressure, relation-specific behavior, concealment strategy, iceberg trace, and personalized cost.

Do not give decorative quirks.

### Living world material

Use for world pressure through household, village, road, market, weather, animal, tool, rumor, taboo, unfinished work, or social habit.

Do not use scenery as mood label.

### Genre technique

Use for mystery clue, delayed answer, fair withholding, survival calculation, cost ledger, promise/payoff, off-POV pressure return, false proof, and consequence chain.

Do not import systems, organizations, worldviews, or plot rhythm from benchmark novels.

### Register / style technique

Use for Vietnamese life, Viet Dao register, controlled Sino-Vietnamese, anti-translation syntax, fake-classical avoidance, and modern-flat avoidance.

### Rhythm / layout technique

Use for sentence length, paragraph breath, line break purpose, aftershock line, mobile readability, and short-line density.

### Edit decision technique

Use to choose whether the passage needs line surgery, component balance, beat repair, living world repair, character repair, or full scene rewrite.

## Safe repair

Safe repair may:

- select one craft move that matches the scene function;
- replace a generic line with a scene-native action, object, body, silence, or material pressure;
- use a sample only to determine direction and degree;
- state a patch principle before changing prose;
- hand off to the relevant gate when the problem is structural.

Safe repair must not:

- imitate sample wording, rhythm, or voice;
- add multiple craft moves to make the passage look rich;
- invent lore, canon, backstory, custom, or character history;
- copy benchmark novels;
- hide weak story structure under prose craft;
- rewrite without exact source text.

## Handoff

If the issue is component mix, hand off to Scene Composition & Component Balance Check.

If the issue is beat structure, hand off to Narrative Beat Escalation & Aftershock Check.

If the issue is living world material, hand off to Living World & Community Motion Check.

If the issue is character voice/body/iceberg, hand off to Character Distinctiveness Check.
