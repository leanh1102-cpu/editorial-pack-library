# SLTD Protagonist Inquiry, Inner Reasoning & Clue Chain Pressure Protocol

This gate controls Dai Phong's active curiosity, private reasoning, small tests, and clue chaining.

It sits under protagonist advancement: advancement says what Dai Phong gains; inquiry says how he actively seeks, tests, misreads, hides, and connects it.

## Core rule

Dai Phong must not only receive events. He must form child-scale private questions, test small clues, keep details, misread safely, and return to clues later.

```text
INQUIRY_CHAIN = pressure sign -> private question -> child-scale hypothesis -> small test -> partial read or misread -> kept detail -> small secret -> next return
PRIVATE_QUESTION = what Dai Phong silently asks because a daily pattern broke
CHILD_SCALE_HYPOTHESIS = a concrete guess based on body, object, person, animal, work, price, name, or route, not abstract system logic
SMALL_TEST = a low-power action: touch again, move object, ask sideways, wait, compare animal behavior, repeat a name, check heat/cold, look for a witness
PARTIAL_READ = what he can reasonably infer now
MISREAD = the wrong or incomplete conclusion that keeps future growth possible
KEPT_DETAIL = a clue he does not say aloud because saying it may create cost
SMALL_SECRET = a tiny discovery that changes his method, not a major lore reveal
NEXT_RETURN = where the clue or method must return later
```

A scene with supernatural signs is weak if it creates mood but no private question, no small test, no kept detail, and no return path.

## Use when

- Dai Phong seems passive, acted upon, or only receives adult explanation;
- supernatural or eerie material is present but does not pressure curiosity;
- clues appear but are not chained by Dai Phong's own reasoning;
- inner thought is missing, too abstract, too adult, or only names emotion;
- a scene needs Dai Phong to try, compare, misread, hide, and learn a small secret;
- C030 or later low-lore scenes need world-rule sensitivity without system knowledge;
- the user asks for private monologue, reasoning, clue chain, curiosity, testing, or small mystery payoff.

## Authority

This gate does not authorize new lore, new clues, new powers, or new revelations.

If exact prose is being patched, run Source Surface Check first.

If the clue depends on timeline, POV, reveal window, folklore truth, or canon, hand off to Timeline / POV / Foreshadowing / Folklore Check.

## Supernatural pressure rule

A supernatural sign must do at least one of these:

```text
break a daily habit
make an adult avoid a word
make an animal, object, medicine, fire, water, paper, or name behave wrong
force Dai Phong to ask privately why only this thing changed
give him a small test he can perform without power
leave a kept detail or a returnable clue
change how he later reads body, object, name, paper, witness, or route
```

If it only adds cold, fog, silence, dream, omen, or mood, mark SUPERNATURAL_AS_MOOD_ONLY.

## Inner reasoning rule

Dai Phong's inner reasoning should be concrete and short. It should place things beside each other, not explain the world.

Preferred mode:

```text
He puts two or three concrete signs together.
He notices what does not fit.
He chooses one small test or silence.
He keeps one detail back.
```

Avoid:

```text
ancient mechanism explanation
clear metaphysical theory
adult courtroom reasoning
essay-like self-analysis
named system insight
perfect deduction
emotion named before pressure exists
```

## C030 inquiry use

For C030, the cold stone, medicine bowl, Thuy Hoa's hand, Dai Son's breath, silent dog, old paper, Lao Hoac avoiding a word, wrong-called name, or object placed in the house must not be used as prose tags.

They should become pressure signs that Dai Phong can privately compare.

Valid C030 inquiry is:

```text
not system knowledge
not full lore answer
not a lecture about name/body/price/debt
but a small chain: something is wrong -> he compares signs -> he tests or withholds -> he learns the object is not passive -> the clue returns later
```

## Safe repair

Safe repair may:

- identify a broken daily pattern already in source;
- turn a mood-only sign into a private question if the source supports it;
- add a small test only when the source object/action already exists;
- convert abstract inner explanation into concrete comparison;
- move a clue into kept detail instead of reveal;
- mark missing inquiry as a blocker when source is insufficient.

Safe repair must not:

- invent new clues, powers, witnesses, lore facts, or future reveals;
- let Dai Phong solve too much too early;
- make inner monologue longer than the scene can bear;
- turn every eerie sign into a clue;
- replace prose with diagnostic labels.
