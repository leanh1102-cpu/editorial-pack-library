# SLTD Task Router

Map each request to the smallest route.

Base:

```text
boot_task -> source_preflight -> context_capsule_preflight when current source, hidden canon, POV knowledge, source-status separation, or long-range continuity is in scope -> task_intake -> decision_safety
```

Rules:

```text
Run context_capsule_preflight for current/latest source, Notion current manuscript, lock, readiness, Human Chapter Pass, Publication Lock, packet verdict, canon conflict, hidden canon, POV knowledge, object/location/body/debt state, relationship memory, lore retrieval, legacy source risk, summary-vs-source risk, or long-range continuity.
Run reference_anchored_story_quality_check for POLARIS-style longform story quality, reference-anchored quality, long rewrite/chapter quality, length adherence, bloat, drift, over-summary, over-explanation, late-output collapse, or sustained quality across a long scene/chapter/packet. Use as quality stress test only.
Run corpus_topic_thread_discovery_check for TopicGPT-style topic modeling, corpus topic discovery, thread discovery, motif clusters, repeated AI-smell clusters, packet/arc/series map, topic gaps, thread drift, or source assignments with quote anchors. Use map-level navigation only.
Run narrative_claim_verification_check for CLIPPER-style claim verification, true/false claims, false twins, status claims, canon claims, continuity claims, POV knowledge claims, source conflicts, readiness claims, Human Chapter Pass, Publication Lock, or whether a claim is TRUE/FALSE/UNCERTAIN.
Run multi_constraint_instruction_check for Suri-style multi-constraint instruction following, corrupted constraints, rewrite/draft/readiness constraint ledgers, or any task where source/canon/POV/scene/style/surface/wordcount constraints must be preserved together.
Run editorial_harm_anticipation_check for AHA-style harm anticipation, REDTEAM, PREMORTEM, readiness risk, lock risk, false readiness, reveal leak, over-polish harm, style-over-character harm, packet failure, or high-risk rewrite failure vignettes.
Run narrative_feature_audit for StoryScope-style narrative features, structural AI smell, theme overexplained, causal tidiness, single-track plot risk, protagonist understanding as resolution, temporal flatness, weak reveal/recontextualization, decorative body/sensory detail, or narrative diversity.
Run author_writing_sheet_check for Author Writing Sheet, claim-evidence style memory, sample-backed author profile, prompt-specific story rules, or author style claims that need evidence before author voice fingerprint / author-aligned draft.
Run character_voice_dialogue_staging_check for dialogue, multi-character scenes, character voice, relationship memory, silence, interruptions, location staging, usable objects, tone, comedy, grief, or physical action.
Run author_voice_fingerprint_check for author voice, voice DNA, style guide, writing sample analysis, voice match, personal style, or prose that sounds unlike the author.
Run author_aligned_ghostwriter_draft only when source/canon/scene controls are clear and the user asks for author-aligned drafting, ghostwriter-style drafting, or writing in the author's voice.
Run general_chapter_feedback_matrix_check for general feedback plus chapter feedback, packet/arc/hồi review, or matrix-style output.
Run tracking_logic_ledger_check for logic continuity, state trace, knowledge state, object/residue/thread tracking, payoff debt, status/pass trace, downstream risk, or verify target.
Run structural_spine_outline_preprose_check before prose when outline, card, packet, border, act, arc, hoi, chapter, or scene function is at stake.
Run vietnamese_senior_editor_surface_check for Vietnamese human-surface reading, read-aloud friction, semantic load, repeated AI smell, pass labels, candidate-ready notes, or publication lock risk.
Run human_surface_polish_pass when exact prose is source-safe and earlier gates permit prose, but the passage still reads synthetic, falsely smooth, same-voiced, over-clean, symbol-first, or thin in body/object/relationship pressure.
Run source_surface_check before exact prose, status, readiness, patch, line edit, topic assignment requiring current evidence, claim verification, multi-constraint ledger, harm anticipation, longform quality verdict, narrative-feature verdict, human-surface polish, author-aligned ghostwriter drafting, or lock verdict.
Stop at the first real blocker.
```
