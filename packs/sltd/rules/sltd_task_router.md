# SLTD Task Router

Map each request to the smallest route.

Base:

```text
boot_task -> source_preflight -> context_capsule_preflight when current source, hidden canon, POV knowledge, source-status separation, or long-range continuity is in scope -> task_intake -> decision_safety
```

Routes:

```text
context capsule preflight: sltd_source_fidelity_anti_compression -> sltd_context_capsule_lore_retrieval_discipline -> tracking_logic_ledger_check if state/knowledge/object/residue/thread/pass/downstream risk is affected -> structural_spine_outline_preprose_check if scene function, chapter card, scene packet, or border is unclear -> character_voice_dialogue_staging_check if voice, relationship, silence, presence, or location staging is affected -> vietnamese_senior_editor_surface_check if exact surface, Human Chapter Pass, or Publication Lock is in scope -> context_capsule_preflight -> node_checkpoint
entry route governance check: sltd_entry_route_governance_gate_budget_protocol -> entry_route_governance_check -> node_checkpoint
character voice dialogue staging check: sltd_source_fidelity_anti_compression -> sltd_context_capsule_lore_retrieval_discipline if current source, hidden canon, POV knowledge, object state, relationship memory, or long-range context is in scope -> sltd_character_voice_dialogue_relationship_location_gate -> tracking_logic_ledger_check if relationship memory or knowledge/object state changes -> sltd_author_voice_fingerprint_ghostwriter_discipline if author voice may flatten character voice -> vietnamese_senior_editor_surface_check if exact dialogue surface is in scope -> character_voice_dialogue_staging_check -> node_checkpoint
author voice fingerprint check: sltd_source_fidelity_anti_compression -> AUTHOR_WORKING_PROFILE -> AUTHOR_TASTE_EXAMPLES -> sltd_author_voice_fingerprint_ghostwriter_discipline -> sltd_context_capsule_lore_retrieval_discipline if current source, hidden canon, POV knowledge, source-status separation, object/location/body/debt state, relationship memory, or long-range continuity is in scope -> character_voice_dialogue_staging_check if dialogue/character voice is being compared -> vietnamese_senior_editor_surface_check if exact Vietnamese surface is in scope -> author_voice_fingerprint_check -> node_checkpoint
author aligned ghostwriter draft: source_surface_check or source_preflight for current packet -> sltd_context_capsule_lore_retrieval_discipline when current source, hidden canon, POV knowledge, source-status separation, object/location/body/debt state, relationship memory, or long-range continuity is in scope -> sltd_structural_spine_outline_preprose_borderbound_gate if scene function or prose permission is unclear -> sltd_tracking_logic_ledger_traceability_gate if state/object/debt/residue/thread/downstream risk is affected -> sltd_character_voice_dialogue_relationship_location_gate if dialogue/voice/relationship/staging is in scope -> sltd_author_voice_fingerprint_ghostwriter_discipline -> author_aligned_ghostwriter_draft -> human_surface_polish_pass if synthetic-surface risk remains -> node_checkpoint
general chapter feedback matrix check: sltd_source_fidelity_anti_compression -> sltd_context_capsule_lore_retrieval_discipline if current source, packet scope, canon status, or long-range context is in scope -> sltd_general_chapter_feedback_matrix_output_protocol -> structural_spine_outline_preprose_check if spine/source status is required -> tracking_logic_ledger_check if logic trace is required -> character_voice_dialogue_staging_check if dialogue/staging is a packet issue -> author_voice_fingerprint_check if author-voice match is a packet issue -> vietnamese_senior_editor_surface_check if human surface/pass integrity is required -> general_chapter_feedback_matrix_check -> node_checkpoint
tracking logic ledger check: sltd_source_fidelity_anti_compression -> sltd_context_capsule_lore_retrieval_discipline if current source, hidden canon, POV knowledge, or long-range continuity is in scope -> sltd_tracking_logic_ledger_traceability_gate -> tracking_logic_ledger_check -> node_checkpoint
structural spine outline pre-prose check: sltd_source_fidelity_anti_compression -> sltd_context_capsule_lore_retrieval_discipline if current source, scene packet, chapter card, canon status, or long-range context is in scope -> sltd_structural_spine_outline_preprose_borderbound_gate -> tracking_logic_ledger_check if state/thread/object/knowledge trace affects prose permission -> structural_spine_outline_preprose_check -> node_checkpoint
vietnamese senior editor surface check: sltd_source_fidelity_anti_compression -> sltd_context_capsule_lore_retrieval_discipline if current source, hidden canon, POV knowledge, or pass/source status is in scope -> sltd_vietnamese_senior_editor_surface_pass_integrity_gate -> tracking_logic_ledger_check if pass/status trace or downstream risk is unclear -> character_voice_dialogue_staging_check if voice/staging is the surface blocker -> author_voice_fingerprint_check if author style mismatch is the surface blocker -> vietnamese_senior_editor_surface_check -> node_checkpoint
human surface polish pass: source_surface_check when exact prose is being patched -> sltd_source_fidelity_anti_compression -> sltd_context_capsule_lore_retrieval_discipline if current source, hidden canon, POV knowledge, source-status separation, object/location/body/debt state, relationship memory, or long-range continuity is in scope -> sltd_structural_spine_outline_preprose_borderbound_gate if scene function or prose permission is unclear -> sltd_tracking_logic_ledger_traceability_gate if state/object/debt/residue/thread/downstream risk is affected -> sltd_character_voice_dialogue_relationship_location_gate if voice, relationship, silence, presence, dialogue, or location staging is in scope -> sltd_author_voice_fingerprint_ghostwriter_discipline if author voice match or ghostwriter output is being polished -> sltd_vietnamese_senior_editor_surface_pass_integrity_gate -> sltd_human_surface_polish_anti_synthetic_gate -> human_surface_polish_pass -> node_checkpoint
readiness: source_surface_check -> context_capsule_preflight -> structural_spine_outline_preprose_check -> tracking_logic_ledger_check -> character_voice_dialogue_staging_check if dialogue/staging affects human read -> author_voice_fingerprint_check if author voice mismatch affects human read -> vietnamese_senior_editor_surface_check -> human_surface_polish_pass if prose is source-safe but synthetic-surface risk remains -> targeted blockers -> publishing_readiness_reviewer -> chapter_readiness_check -> node_checkpoint
packet review: source_preflight -> context_capsule_preflight when current source, packet scope, canon status, hidden canon, or long-range continuity is in scope -> structural_spine_outline_preprose_check -> tracking_logic_ledger_check -> relevant gates as evidence requires -> general_chapter_feedback_matrix_check or result_report -> node_checkpoint
```

Rules:

```text
Run context_capsule_preflight for current/latest source, Notion current manuscript, lock, readiness, Human Chapter Pass, Publication Lock, packet verdict, canon conflict, hidden canon, POV knowledge, object/location/body/debt state, relationship memory, lore retrieval, legacy source risk, summary-vs-source risk, or long-range continuity.
Run character_voice_dialogue_staging_check for dialogue, multi-character scenes, character voice, relationship memory, silence, interruptions, location staging, usable objects, tone, comedy, grief, or physical action.
Run author_voice_fingerprint_check for author voice, voice DNA, style guide, writing sample analysis, voice match, personal style, or prose that sounds unlike the author.
Run author_aligned_ghostwriter_draft only when source/canon/scene controls are clear and the user asks for author-aligned drafting, ghostwriter-style drafting, or writing in the author's voice.
Run general_chapter_feedback_matrix_check for general feedback plus chapter feedback, packet/arc/hồi review, or matrix-style output.
Run tracking_logic_ledger_check for logic continuity, state trace, knowledge state, object/residue/thread tracking, payoff debt, status/pass trace, downstream risk, or verify target.
Run structural_spine_outline_preprose_check before prose when outline, card, packet, border, act, arc, hoi, chapter, or scene function is at stake.
Run vietnamese_senior_editor_surface_check for Vietnamese human-surface reading, read-aloud friction, semantic load, repeated AI smell, pass labels, candidate-ready notes, or publication lock risk.
Run human_surface_polish_pass when exact prose is source-safe and earlier gates permit prose, but the passage still reads synthetic, falsely smooth, same-voiced, over-clean, symbol-first, or thin in body/object/relationship pressure.
Run source_surface_check before exact prose, status, readiness, patch, line edit, human-surface polish, author-aligned ghostwriter drafting, or lock verdict.
Stop at the first real blocker.
```
