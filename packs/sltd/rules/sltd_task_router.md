# SLTD Task Router

Map each request to the smallest route.

Base:

```text
boot_task -> source_preflight -> task_intake -> decision_safety
```

Routes:

```text
entry route governance check: sltd_entry_route_governance_gate_budget_protocol -> entry_route_governance_check -> node_checkpoint
general chapter feedback matrix check: sltd_source_fidelity_anti_compression -> sltd_general_chapter_feedback_matrix_output_protocol -> structural_spine_outline_preprose_check if spine/source status is required -> tracking_logic_ledger_check if logic trace is required -> vietnamese_senior_editor_surface_check if human surface/pass integrity is required -> general_chapter_feedback_matrix_check -> node_checkpoint
tracking logic ledger check: sltd_source_fidelity_anti_compression -> sltd_tracking_logic_ledger_traceability_gate -> tracking_logic_ledger_check -> node_checkpoint
structural spine outline pre-prose check: sltd_source_fidelity_anti_compression -> sltd_structural_spine_outline_preprose_borderbound_gate -> tracking_logic_ledger_check if state/thread/object/knowledge trace affects prose permission -> structural_spine_outline_preprose_check -> node_checkpoint
vietnamese senior editor surface check: sltd_source_fidelity_anti_compression -> sltd_vietnamese_senior_editor_surface_pass_integrity_gate -> tracking_logic_ledger_check if pass/status trace or downstream risk is unclear -> vietnamese_senior_editor_surface_check -> node_checkpoint
readiness: source_surface_check -> structural_spine_outline_preprose_check -> tracking_logic_ledger_check -> vietnamese_senior_editor_surface_check -> targeted blockers -> publishing_readiness_reviewer -> chapter_readiness_check -> node_checkpoint
packet review: source_preflight -> structural_spine_outline_preprose_check -> tracking_logic_ledger_check -> relevant gates as evidence requires -> general_chapter_feedback_matrix_check or result_report -> node_checkpoint
```

Rules:

```text
Run general_chapter_feedback_matrix_check for general feedback plus chapter feedback, packet/arc/hồi review, or matrix-style output.
Run tracking_logic_ledger_check for logic continuity, state trace, knowledge state, object/residue/thread tracking, payoff debt, status/pass trace, downstream risk, or verify target.
Run structural_spine_outline_preprose_check before prose when outline, card, packet, border, act, arc, hoi, chapter, or scene function is at stake.
Run vietnamese_senior_editor_surface_check for Vietnamese human-surface reading, read-aloud friction, semantic load, repeated AI smell, pass labels, candidate-ready notes, or publication lock risk.
Run source_surface_check before exact prose, status, readiness, patch, line edit, or lock verdict.
Stop at the first real blocker.
```
