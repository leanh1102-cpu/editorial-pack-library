# SLTD Task Router

Map each request to the smallest route.

Base:

```text
boot_task -> source_preflight -> task_intake -> decision_safety
```

Routes:

```text
entry route governance check: sltd_entry_route_governance_gate_budget_protocol -> entry_route_governance_check -> node_checkpoint
structural spine outline pre-prose check: sltd_source_fidelity_anti_compression -> sltd_structural_spine_outline_preprose_borderbound_gate -> structural_spine_outline_preprose_check -> node_checkpoint
vietnamese senior editor surface check: sltd_source_fidelity_anti_compression -> sltd_vietnamese_senior_editor_surface_pass_integrity_gate -> vietnamese_senior_editor_surface_check -> node_checkpoint
supernatural event residue check: sltd_source_fidelity_anti_compression -> sltd_supernatural_event_residue_dread_amplitude_gate -> structural_spine_outline_preprose_check if residue may cross spine -> vietnamese_senior_editor_surface_check if residue prose is overloaded -> supernatural_event_residue_check -> node_checkpoint
protagonist inquiry check: sltd_source_fidelity_anti_compression -> sltd_protagonist_inquiry_inner_reasoning_clue_chain_gate -> structural_spine_outline_preprose_check if inquiry may cross scene function -> vietnamese_senior_editor_surface_check if inner reasoning is stiff -> protagonist_inquiry_check -> node_checkpoint
protagonist advancement check: sltd_source_fidelity_anti_compression -> sltd_protagonist_advancement_growth_route_gate -> structural_spine_outline_preprose_check if gain must fit spine -> vietnamese_senior_editor_surface_check if gain prose/status is uncertain -> protagonist_advancement_check -> node_checkpoint
scene rewrite: source_surface_check -> structural_spine_outline_preprose_check -> vietnamese_senior_editor_surface_check -> entry_route_governance_check if downstream gates compete -> first_pass_editorial_workflow -> targeted gates as needed -> rewrite_scene -> node_checkpoint
line surgery: source_surface_check -> structural_spine_outline_preprose_check if border risk exists -> vietnamese_senior_editor_surface_check -> line_surgery -> node_checkpoint
readiness: source_surface_check -> structural_spine_outline_preprose_check -> vietnamese_senior_editor_surface_check -> targeted blockers -> publishing_readiness_reviewer -> chapter_readiness_check -> node_checkpoint
```

Rules:

```text
Run vietnamese_senior_editor_surface_check for Vietnamese human-surface reading, read-aloud friction, semantic load, repeated AI smell, pass labels, candidate-ready notes, or publication lock risk.
Run structural_spine_outline_preprose_check before prose when outline, card, packet, border, act, arc, hoi, chapter, or scene function is at stake.
Run source_surface_check before exact prose, status, readiness, patch, line edit, or lock verdict.
Stop at the first real blocker.
```
