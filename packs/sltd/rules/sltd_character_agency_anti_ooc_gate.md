# SLTD Character Agency & Anti-OOC Gate

This gate prevents characters from being forced into plot beats, scene cards, clue delivery, or explanation duty.

It protects character agency: what a character wants, fears, knows, hides, misreads, chooses, and pays.

## Core rule

A scene must not use a character as a tool for the outline.

```text
CHARACTER AGENCY = want + fear + knowledge limit + pressure + choice + cost
PLOT FUNCTION = what the scene needs to accomplish
SAFE SCENE = character agency drives or resists plot function
OOC/OCC RISK = plot function forces character behavior without enough pressure
```

A character may serve the plot only through believable pressure, relation, habit, ignorance, misread, debt, fear, bodily limit, or practical need.

## Use when

- the user says OOC, OCC, character forced, character-as-plot-tool, or scene feels arranged;
- a character says the exact thing the scene needs rather than what they would say;
- a character notices the exact clue because the plot needs it;
- dialogue carries outline labels, rules, warnings, or exposition too cleanly;
- objects appear in sequence as proof items and characters react on cue;
- a scene answers its scene card but does not feel lived;
- a rewrite fixes prose but keeps false agency.

## Authority

This gate sits below:

```text
current user instruction
current Notion source or user-provided source packet
source fidelity gate
canon guard
evidence discipline
role boundary contracts
```

It must not add canon, change locked outcome, invent motive, or replace current source with psychological explanation.

## Agency check

For each key character in scope, identify:

```text
CHARACTER:
WANT:
FEAR:
KNOWS:
DOES NOT KNOW:
HIDES / AVOIDS:
MISREADS:
PRESSURE ACTING ON THEM:
CHOICE MADE:
VISIBLE COST:
PLOT FUNCTION BEING SERVED:
AGENCY STATUS:
```

If want, fear, knowledge limit, pressure, choice, or cost is missing, do not polish the scene as ready.

## Plot pressure test

Ask:

```text
Would this character still do this if the scene did not need the next clue?
Would they say this in this room, to this person, under this risk?
What practical problem forces this action now?
What would they avoid saying?
What would they misunderstand?
Who or what interrupts the neat route?
What cost remains after the scene moves on?
```

If the only answer is `because the scene needs it`, mark OOC/OCC risk.

## Safe repair

Safe repair may:

- add hesitation, refusal, delay, misread, or avoidance with source basis;
- make the object interrupt a practical task instead of presenting itself as a clue;
- let dialogue dodge, scold, hide, mishear, or stop short;
- force a choice through illness, money, debt, gossip, household work, body limit, or relation pressure;
- make a character notice a clue because of work they are already doing;
- restore consequence after a character chooses.

Safe repair must not:

- add new backstory;
- invent a new motive;
- add a new lore explanation;
- change the scene outcome;
- make characters smarter or more theatrical than source allows;
- overwrite source surface without exact text.

## Dynamic range relation

Character agency and dynamic range are linked.

Do not create force by making everyone louder.

Create force by making choice, fear, silence, body, object, relation, or cost harder to avoid.

## Patch rule

For local patch:

```text
OLD:
PROBLEM LABEL:
WHY IT FORCES CHARACTER:
NEW:
AGENCY RESTORED BY:
PLOT FUNCTION PRESERVED:
RISK:
```

If exact source text is missing, do not patch. Run source surface check.

## Handoff

If character function is unclear, hand off to Story Doctor.

If agency exists but cadence is flat, hand off to Dynamic Range Check.

If agency exists but prose sounds artificial, hand off to Vietnamese Line Editor or Line Surgery.

If canon or locked outcome is unclear, hand off to Canon Guard.
