# SLTD Scene Composition Ratio & Component Balance Gate

This gate controls scene composition by function: dialogue, action/blocking, inner thought, setting/living world, object/clue, sensory/body, silence/pause, summary/transition, and aftershock.

It uses soft diagnostic bands. It must not turn prose into a checklist or formula.

## Core rule

Composition follows scene function.

Percentages are diagnostic bands, not writing formulas.

```text
SCENE COMPOSITION = how the scene distributes reader attention across dialogue, action, thought, place, object, body, silence, summary, and aftershock
COMPONENT BALANCE = whether each component serves pressure, relation, information, cost, movement, or reader breath
FAKE BALANCE = all components are present but none of them truly move the scene
```

A component is valid only if it changes pressure, relation, information, cost, movement, or reader breath.

Do not add a component only to satisfy a ratio.

## Use when

- a scene feels like too much dialogue, action, inner thought, description, silence, summary, or sensory texture;
- a scene has all components but still reads checklist-made;
- dialogue replaces action;
- inner thought explains instead of pressurizing choice;
- setting is decorative rather than active;
- object/clue is a label rather than anchor;
- sensory/body texture hides missing structure;
- summary replaces live scene;
- aftershock is missing or overused;
- the user asks how much dialogue/action/interior/description a scene should contain.

## Authority

This gate sits below:

```text
current user instruction
current Notion source or user-provided source packet
source fidelity gate
canon guard
evidence discipline
role boundary contracts
```

It must not rewrite from summary, change canon, add plot, or force every scene into the same component mix.

## Soft composition bands

Use these as warning bands, not law.

### Dialogue-driven scene

```text
Dialogue: 35-55%
Action / blocking: 15-25%
Inner thought: 5-15%
Setting / object / sensory: 15-25%
Aftershock: 5-10%
```

Use for argument, interrogation, bargaining, social concealment, or relational pressure.

Red flag: dialogue above 60% without object, body, silence, or relation pressure.

### Action / pursuit / danger scene

```text
Action / blocking: 35-55%
Sensory / body: 15-25%
Dialogue: 0-15%
Inner thought: 0-10%
Setting / obstacle: 15-30%
Aftershock: 5-10%
```

Red flag: long inner thought during immediate danger, or action as motion list without pressure change.

### Discovery / mystery scene

```text
Object / clue: 20-35%
Action / handling: 15-25%
Setting / living world: 15-25%
Dialogue: 10-25%
Inner thought: 5-15%
Aftershock: 5-10%
```

Red flag: clue explained by narration before object, handling, cost, or witness earns it.

### Aftermath / decompression scene

```text
Small action / daily task: 20-35%
Silence / pause: 10-20%
Object / residue: 15-25%
Dialogue: 5-20%
Inner thought: 10-20%
Setting / living world: 10-20%
```

Red flag: only sitting and thinking, or only retelling what already happened.

### Travel / transition / connective scene

```text
Action / movement: 25-40%
Setting / living world: 20-35%
Dialogue: 5-20%
Inner thought: 5-15%
Object / clue / rumor: 5-20%
```

Red flag: movement from A to B without new pressure, information, cost, or promise.

### High-turn / climax scene

```text
Action / choice: 25-40%
Dialogue: 10-30%
Object / anchor: 10-25%
Body / sensory: 10-20%
Inner thought: 0-10%
Aftershock: 10-20%
```

Red flag: climax without result, cost, changed state, or promise/payoff movement.

## Component validity test

For each component, ask:

```text
Dialogue: does it change relation, pressure, information, concealment, or choice?
Action / blocking: does it change position, access, cost, danger, or rhythm?
Inner thought: does it reveal conflict, misread, refusal, cost, or pressure rather than explain emotion?
Setting / living world: does it push back or move beyond POV?
Object / clue: does it anchor action, cost, evidence, misunderstanding, or future pressure?
Sensory / body: does it expose cost, limit action, or change reader breath?
Silence / pause: does it change relation or pressure, or is it decorative?
Summary / transition: does it compress only what does not need dramatizing?
Aftershock: does it leave inherited pressure or changed state?
```

If a component does not answer, it may be decorative or checklist texture.

## Fake balance test

Ask:

```text
Are components present because the scene needs them, or because the edit is trying to look complete?
Would removing a component change pressure, relation, information, cost, or reader breath?
Is one weak component being hidden under more sensory/body/detail texture?
Does the dominant component match scene function?
Does the missing component explain why the scene feels flat?
```

If every component is present but none moves the scene, mark fake balance.

## Safe repair

Safe repair may:

- rebalance components toward the scene function;
- reduce dialogue that only transfers information;
- replace explanatory inner thought with action, object, or choice pressure;
- add blocking when bodies in space are unclear;
- make existing setting, object, body, or silence affect pressure;
- cut sensory texture that hides weak structure;
- compress summary that should not be dramatized;
- dramatize a summary only when it carries pressure, choice, or cost;
- add aftershock only when a turn needs inherited pressure.

Safe repair must not:

- apply percentages mechanically;
- add components just to fill a band;
- make every scene balanced the same way;
- add plot, canon, new lore, new character, or new event;
- turn quiet scenes into action scenes;
- use component balance to hide missing scene function.


If exact source text is missing, do not patch. Run Source Surface Check.

## Handoff

If scene function is unclear, hand off to First-Pass Editorial Workflow or Scene-First Prose Judgment.

If the issue is beat escalation, hand off to Narrative Beat Escalation & Aftershock Check.

If setting/living world is decorative, hand off to Living World & Community Motion Check.

If dialogue voice is collapsed, hand off to Character Distinctiveness or Vietnamese Line Surgery.

If paragraphing/layout creates false rhythm, hand off to Webnovel Paragraphing & Layout Check.
