# SLTD Anti-AI Composite Failure Gate

This gate catches composite AI-ness after many correct-looking passes.

It is for scenes or chapters that satisfy several checklists but still read as arranged, synthetic, over-polished, or not written by a human hand.

## Core rule

A scene can be correct and still feel AI-made.

Composite AI failure happens when multiple safe repairs stack into a scene that is cleaner, more complete, and more functional, but less lived.

## Use when

- a chapter has many green passes but still fails human read;
- a scene feels like a scene card converted into prose;
- several repairs have added objects, body beats, silence, dialogue pressure, or folklore, but the scene still feels assembled;
- characters, objects, narrator, and dialogue all serve the scene function too neatly;
- the user says AI-ish, synthetic, checklist, arranged, over-polished, collage, fake human texture, or not human-written.

## Authority

This gate sits below:

```text
current user instruction
current Notion source or user-provided source packet
source fidelity gate
canon guard
evidence discipline
role boundary contracts
character agency gate
dynamic range gate
```

It must not add canon, change locked outcome, or override current source.

## Composite failure types

Check these failures together, not one by one only:

```text
SCENE_CARD_VISIBILITY
OBJECT_AS_PROOF_ITEM
EXPLANATION_DUTY_DIALOGUE
UNIVERSAL_NARRATOR_VOICE
CONSEQUENCE_VACUUM
REPAIR_COLLAGE
FALSE_HUMAN_TEXTURE
CLEAN_TRANSITION_DISEASE
NEGATIVE_EXPLANATION_HABIT
FALSE_READINESS
```

## Failure definitions

### SCENE_CARD_VISIBILITY

The scene visibly answers its planning fields but does not feel like lived time.

Signs:

- scene question is too visible;
- must-show items arrive in order;
- characters move between beats with little resistance;
- scene ends as soon as its function is fulfilled.

### OBJECT_AS_PROOF_ITEM

An object exists to prove meaning instead of forcing action.

Ask:

```text
Does the object block, delay, cost, expose, hide, stain, break, or change a choice?
```

If not, the object may be a proof item.

### EXPLANATION_DUTY_DIALOGUE

Dialogue explains the outline, risk, rule, emotion, or meaning too cleanly.

### UNIVERSAL_NARRATOR_VOICE

Narration sounds like one stable assistant voice rather than scene-bound perception.

Signs:

- narrator names theme before pressure earns it;
- transitions are smooth but generic;
- every scene has the same explanatory distance.

### CONSEQUENCE_VACUUM

A decision, discovery, lie, or risk leaves no visible trace.

### REPAIR_COLLAGE

Multiple correct repairs stack without one governing scene pressure.

Signs:

- object beat, body beat, silence, folklore, and dialogue pressure all appear;
- each element is correct alone;
- together they feel assembled rather than inevitable.

### FALSE_HUMAN_TEXTURE

Hands, breath, silence, animals, objects, or household details appear as texture but do not alter action, relation, cost, or choice.

### CLEAN_TRANSITION_DISEASE

Transitions smooth away interruption, awkwardness, social pressure, or practical friction.

### NEGATIVE_EXPLANATION_HABIT

Narration explains by negation rather than concrete pressure.

Examples:

```text
not ordinary
could not ignore
not merely
no longer simple
```

### FALSE_READINESS

A chapter is treated as ready because many sub-passes are green while human pass, publication lock, source conflict, or rewrite notes still block it.

## Repair level

Choose one:

```text
NO_PATCH_NEEDED
LINE_SURGERY_ONLY
AGENCY_REPAIR_FIRST
DYNAMIC_RANGE_REPAIR_FIRST
SCENE_REWRITE_REQUIRED
CHAPTER_REMERGE_REQUIRED
READINESS_BLOCKED
```

## Repair principles

Do:

- choose one governing scene pressure;
- remove decorative texture that does not change action;
- make objects force decisions, not meanings;
- make dialogue dodge, resist, misread, or cost something;
- preserve mystery while increasing practical pressure;
- separate human-readiness evidence from prose cleanliness.

Do not:

- add more texture to hide synthetic structure;
- patch every sentence when scene function is false;
- make all characters louder;
- add canon to create depth;
- claim readiness from green sub-passes alone;
- use digest as source text.

## Patch rule

If exact source text is available:

```text
OLD:
COMPOSITE FAILURE:
WHY IT READS AI:
NEW:
WHAT WAS REMOVED:
WHAT NOW DRIVES THE SCENE:
RISK:
```

If exact source text is missing, do not patch. Run source surface check.

## Handoff

If character agency fails, hand off to Character Agency Check.

If cadence or pressure fails, hand off to Dynamic Range Check.

If exact source is missing, hand off to Source Surface Check.

If readiness conflict appears, hand off to Publishing Readiness Reviewer.
