# SLTD Context Window Strategy

Use this rule when a task may exceed the active LLM context window.

## Main rule

Do not load the whole project into the active window.

Load the smallest useful slice:

```text
source preflight
current scope
local scene or chapter
needed canon node
needed skill files
node ledger
```

## Slice by task

### Scene rewrite

Use:

- Scene Bank source;
- Scene Question;
- Must Show;
- Must Not Reveal;
- current chapter lock note;
- canon guard;
- intensity rules;
- prose rules.

Do not load the whole packet unless the scene depends on packet payoff.

### Chapter audit

Use:

- Chapter Index row;
- chapter page;
- linked Scene Bank when needed;
- Chapter Review;
- story and intensity rules.

### Packet read

Use:

- Series Manuscript packet;
- Chapter Index lock status;
- blocker chapters;
- story arc audit;
- publishing readiness.

Do not line edit all chapters during packet read.

## Compression rule

Create a context brief before action if more than three source nodes are involved.

The brief must name:

```text
IN CONTEXT:
NOT IN CONTEXT:
ASSUMPTIONS:
RISK IF WRONG:
```

## Refresh rule

If the answer starts relying on memory instead of opened source, refresh the source or stop.
