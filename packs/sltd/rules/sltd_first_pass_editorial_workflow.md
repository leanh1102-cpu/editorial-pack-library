# SLTD First-Pass Editorial Workflow

This workflow turns scene-first judgment into the default first editing pass.

It reduces later cleanup by making the first pass diagnose scene pressure, prose life, and edit layer before any checklist-style gate is used.

## Core rule

Edit first as a human prose editor. Verify after.

```text
FIRST PASS = source surface + scene intake + diagnosis + one edit strategy + human-read prose pass
GATES = targeted later checks, not the first writing method
QUALITY = natural Vietnamese prose with scene pressure, character behavior, and rhythm working together
```

Do not run all gates before the first edit.

Do not turn the first edit into a checklist-filling exercise.

## Use when

- beginning a rewrite, line edit, line surgery, scene repair, or chapter repair;
- the user asks for a first pass, initial edit, rewrite, prose improvement, or natural Vietnamese prose;
- the scene has not yet received a full human-style editorial read;
- prior outputs over-used gates, labels, or checklist compliance;
- the goal is to reduce later anti-AI cleanup.

## Authority

This workflow sits below:

```text
current user instruction
current Notion source or user-provided source packet
source fidelity gate
canon guard
evidence discipline
role boundary contracts
```

It must not add canon, change locked outcome, or edit from compressed source.

## Workflow steps

### 1. Source surface

Confirm:

```text
SOURCE USED:
SOURCE SURFACE:
CURRENT VS LEGACY:
SCOPE:
LOCK / CANON BLOCKERS:
```

If exact source text is missing for prose work, stop and run Source Surface Check.

### 2. Scene-first intake

Before editing, identify:

```text
SCENE FUNCTION:
GOVERNING PRESSURE:
WHO IS UNDER PRESSURE:
PRACTICAL ACTION:
WHAT MUST STAY UNSAID:
WHAT MUST BE FELT:
```

If governing pressure is missing, stop before prose patch and hand off to Story Doctor or Scene-First Prose Judgment.

### 3. Editorial diagnosis

Diagnose the primary edit layer:

```text
SOURCE / CANON
STORY FUNCTION
CHARACTER AGENCY
SCENE PRESSURE / CADENCE
PROSE LIFE
LINE RHYTHM
COPYEDIT / PROOFREAD
READINESS
```

Choose the earliest failing layer. Do not polish later layers over earlier failure.

### 4. Single edit strategy

Choose one main repair strategy:

```text
REWRITE SCENE
REPAIR AGENCY
RESTORE PRESSURE
REMOVE CHECKLIST TEXTURE
LINE SURGERY
COPYEDIT ONLY
NO PATCH — NEED SOURCE
```

Do not stack many repair strategies in one first pass unless the user asks for a full rewrite.

### 5. Draft or patch

Write the edit using natural Vietnamese prose.

Prefer:

- concrete action;
- scene-specific pressure;
- dialogue that resists, hides, cuts off, or mishears when appropriate;
- objects that change action;
- sentence rhythm that follows pressure;
- roughness that belongs to the scene.

Avoid:

- showing the checklist;
- decorative body beats;
- object-as-proof-item;
- explanatory transitions;
- same-voice dialogue;
- adding more texture to hide structure.

### 6. Human-read prose pass

After the draft/patch, read like a Vietnamese prose editor:

```text
Does the scene read naturally?
Does the governing pressure remain visible without being explained?
Does dialogue sound like people in the room?
Does the object change action rather than prove meaning?
Is any sentence included only to satisfy a gate?
```

### 7. Targeted gate only if needed

Run only the gate that matches the remaining blocker:

```text
source missing -> Source Surface Check
checklist-first smell -> Scene-First Prose Judgment
synthetic after repairs -> Anti-AI Composite Check
false agency -> Character Agency Check
flat cadence -> Dynamic Range Check
line rhythm only -> Line Surgery
readiness conflict -> Publishing Readiness
```

## Patch rule

If exact source text is available:

```text
OLD:
PRIMARY FAILURE:
NEW:
WHY THIS IS THE FIRST-PASS REPAIR:
POST-READ NOTE:
RISK:
```

If exact source text is missing, do not patch.

## Stop rules

Stop before patch when:

- source surface is missing;
- current vs legacy source is unclear;
- canon or lock status blocks the change;
- governing pressure is missing;
- scene function is unclear;
- the requested edit would require adding canon;
- the task scope exceeds context window.
