# SLTD Intensity Targets

This rule prevents safe-but-thin prose.

## Scale

```text
0 = flat summary
1 = clean but thin
2 = present but safe
3 = baseline pull
4 = strong pull
5 = signature chapter
```

Target:

- regular scene: 3
- cluster turn: 4
- opening or discovery scene: 4 to 5

## Scene forces

Each scene should use at least one force:

1. physical pressure;
2. price pressure;
3. relation pressure;
4. object pressure;
5. secret pressure;
6. choice pressure;
7. mystery pressure.

## Underreach flags

Mark UNDERREACHED when:

- risk is named but not acted out;
- Da Phong gains without cost;
- a strange object asks no new question;
- chapter ends with no changed state;
- debt appears but does not tighten;
- a hard choice becomes soft;
- the scene is cleaner but not sharper.
