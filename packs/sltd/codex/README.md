# SLTD Codex Operating Layer

This folder defines a minimal Codex-ready operating layer for SLTD.

It does not contain live manuscript text.

## Purpose

Use Codex to keep editorial work disciplined:

- source status;
- canon and lock safety;
- scene-function audit;
- voice and dialogue risk;
- AI-smell extraction;
- temporary scaffold labeling;
- human verdict capture.

## Non-purpose

Codex is not a final Vietnamese prose authority.

Codex does not solve the closed thesis objective of making current ChatGPT reliably write emotionally convincing, natural Vietnamese authorial prose for SLTD.

## Folder map

```text
packs/sltd/codex/
  source-map.yml
  role-cards/
  schemas/
  templates/
```

## Working rule

```text
Notion keeps live manuscript.
GitHub keeps rules and Codex roles.
Google Drive keeps historical/reference exports.
Codex keeps discipline.
Human author/editor keeps final prose.
```

## Scaffold rule

Any generated prose must be marked:

```text
AI_SCAFFOLD / NOT_FINAL_PROSE / HUMAN_REWRITE_REQUIRED
```

AI scaffold may help build shape. It must not be mistaken for final literary prose.
