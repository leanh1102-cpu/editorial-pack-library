# Writer Self Review Curriculum

**Status:** `WRITER_SELF_REVIEW-INTEGRATED v0.3.1 / COMPOSITE EVIDENCE`

## Curriculum spine
1. **Review stance** — reread to evaluate, not merely to re-experience author intention.
2. **Detection → diagnosis → strategy** — discomfort is a signal; name the mechanism before editing.
3. **Revision scale** — sentence / paragraph / scene / chapter / dependency chain; blockers before polish.
4. **Reader model** — distinguish `AUTHOR KNOWS` from `READER CAN RECONSTRUCT`.
5. **Preservation contract** — every edit names what must survive.
6. **Targeted passes** — one primary diagnostic question; cross-domain edits require causal necessity.
7. **Regression/version comparison** — local improvement is rejected when meaning, evidence, access, causality, clue, voice/register, rhythm, or information architecture worsens.
8. **Stop/release/learning capture** — stop on saturation/preference-only changes; cap five material passes; no pass 6; release best defensible version and capture narrow learning.
