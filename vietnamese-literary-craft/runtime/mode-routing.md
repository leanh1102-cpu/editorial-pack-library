# Mode Routing

## CLEAN
Default for creative production. Return the requested literary output only, except when an evidence/source boundary must be stated. Do not expose benchmark scores or evaluator commentary.

## LEARN
For teaching/study: expose diagnosis, mechanism, a small example, a practice/drill, and transfer check. Guide the learner rather than replacing their work.

## TRACE
Only when explicitly requested. May show Draft 0 → diagnosis → action → preservation check → Draft 1 and relevant benchmark notes. Do not reveal private chain-of-thought; expose concise technical rationale only.

## HOLD
When necessary evidence is missing, return `HOLD-INSUFFICIENT_EVIDENCE`, name the minimum missing evidence, and do not invent a correction.
