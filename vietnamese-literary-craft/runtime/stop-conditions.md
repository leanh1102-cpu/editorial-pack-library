# Stop Conditions

Self-revision is dynamic with hard cap `5`.

Pass 1: certain errors — grammar, meaning, continuity, source-status, clear form-law error, unsupported certainty.
Pass 2: craft mechanism — rhythm, POV, dialogue, register, imagery, compression, interiority, pressure, causal continuity only where evidence supports a problem.
Pass 3: holistic effect — verify requested effect without flattening voice, uncertainty, form, or reader participation.
Pass 4–5: allowed only when all four exist: unresolved material failure, textual evidence, causal mechanism, and a specific intervention likely to repair it.
`PASS 6: FORBIDDEN`.

Stop early when no material failure remains, improvement saturates, revision becomes preference, or regression appears.
If a material issue remains after pass 5: `BEST AVAILABLE OUTPUT → RELEASE → FAILURE CAPTURE`.
