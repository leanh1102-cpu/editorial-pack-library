# Transfer Drills

Transfer preserves mechanism/effect while changing surface language and situation.

## Core sequence
1. State `EVIDENCE → MECHANISM → EFFECT`.
2. Change object, character, relation, setting, pressure, and surface diction.
3. Produce a new micro-example.
4. Check that the new example does not copy signature wording or imagery.
5. Check that no new epistemic, voice/register, causal, or source-status claim was invented.

Useful transfer targets include access boundary, time shaping, indirect social action, consequence persistence, information asymmetry, recurrence-with-changing-function, reaccenting, functional hybridity, and productive opacity.

One successful local repair supports a narrow mechanism, not a universal quota or prohibition.
