# Recognition Drills

Recognition happens before correction.

## Foundation
- `F1-R1`: underline only observable features; label interpretations separately.
- `F2-R1`: identify mediation, ellipsis, focus marking, reference, and marked order without correcting yet.
- `F3-R1`: mark pauses/fragments/repetition and state supplied pressure/function.
- `F4-R1`: identify speaker/addressee/relation/role/register signals.
- `F5-R1`: sort statements into explicit / implicated / inferred.
- `F6-R1`: trace topic, reference, temporal/causal relations, and connector function.
- `F7-R1`: distinguish direct grounding / functional metaphor / decorative stacking / already-grounded context.
- `F8-R1`: inventory words, syntax, rhythm, recurrence, voice, and structure before interpretation.

## Intermediate
- I1: mark who can know/see/think each clause and flag belief vs story fact.
- I2: label order, duration, frequency changes before judging pacing.
- I3: draw only supported causal arrows; mark mere succession separately.
- I4: separate literal content from social action and relation/register cues.
- I5: classify direct thought, narrated interiority, blending, and semantic duplication.
- I6: map baseline/state/pressure/relation/preparation/aftermath before trait judgment.
- I7: assign a function to every retained detail/object/spatial relation; leave unresolved motif meaning open.
- I8: maintain four columns: happened / believed / said / reader infers.

## Advanced
Identify evidence layer, voice conflict, framing, recurrence function, source status, edition status, and the distinction between productive difficulty and unsupported confusion. Never name an allusion or historical meaning from generic resemblance alone.

## Writer Self Review
Separate problem signal from diagnosed mechanism. Identify author-memory contamination, must-preserve features, revision scale, and saturation/preference churn before proposing an edit.
