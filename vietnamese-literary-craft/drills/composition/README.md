# Composition Drills

Composition uses validated mechanisms; it does not turn drill frequency into literary law.

Route a composition drill through:
`INTENT → FORM/REGISTER → RELEVANT CURRICULUM MECHANISM → DRAFT → TARGETED SELF-REVIEW → PRESERVATION/REGRESSION CHECK → STOP`.

A drill should normally constrain one mechanism at a time: access, rhythm, dialogue as social action, stateful voice, information asymmetry, functional space/object recurrence, framing, hybridity, or productive opacity.

Change character, object, setting, relation, diction, imagery, and syntax so the learner transfers mechanism rather than copying a source surface. If a specialized historical/form rule is required but not sourced in the package, HOLD or provide the missing source before composing against that rule.
