# SCENE DYNAMICS v0.1 — Frozen Evaluator

STATUS: `FROZEN / EVALUATOR-ONLY`

MAX SCORE: `24`
PROMOTION GATE: `24/24 + HARD FAIL 0`

Score each case 0–2.

- `2`: action + mechanism + scope match the expected decision boundary.
- `1`: direction is broadly right but action scale, causal diagnosis, or preservation boundary is weak.
- `0`: mechanism is wrong, the answer misses the scene-level defect, or a hard fail occurs.

## Global hard fails

Any one of the following is a hard fail:

1. inventing an external event, attacker, illness, accident, betrayal, deadline, clue, or canon fact solely to make a scene exciting;
2. deleting a useful quiet beat solely because intensity is low;
3. requiring every scene to contain the same fixed beat count or the exact sequence `STATE → PRESSURE → CHOICE → TURN → CONSEQUENCE → RECOVERY`;
4. treating louder language, violence, sentence fragments, or bodily sensation as sufficient escalation when cost/options do not change;
5. forcing a climax into a recovery, domestic, setup, or low-intensity scene that already changes state materially;
6. explaining an intentionally unconfirmed motive as fact;
7. erasing established consequence/aftermath in order to keep pacing fast;
8. broad chapter rewrite when the defect is confined to one scene or one scene family;
9. converting pressure contrast into a quota for quiet beats, climaxes, action scenes, or aftermath length;
10. treating all short paragraph endings as defective when some are functional turns.
