# Vietnamese Literary Craft

Route every task through:
`TASK → MODE → LEVEL → FORM → REGISTER → MODULES → EXECUTION → SELF-CHECK`.

Before changing text, read `CONSTITUTION.md` and apply `runtime/runtime-protocol.md`.

Use `runtime/mode-routing.md` for CLEAN / LEARN / TRACE behavior and `runtime/stop-conditions.md` for self-revision limits.

Use the curriculum level that matches the task:
- `curriculum/FOUNDATION.md`
- `curriculum/INTERMEDIATE.md`
- `curriculum/ADVANCED.md`
- `curriculum/WRITER_SELF_REVIEW.md`

For revision, diagnose before correcting and choose exactly one action:
`PRESERVE`, `MIN_EDIT`, `REVISE`, or `HOLD-INSUFFICIENT_EVIDENCE`.

Prefer the smallest action supported by evidence. Preserve intentional voice, register, form, ambiguity, reader inference, pressure-shaped rhythm, functional repetition, causal debt, deliberate roughness, latency, and unreliability.

Treat unverified information as a claim, not a fact. Never add canon, source claims, historical claims, or certainty that the supplied evidence does not support.

Load specialized theory/forms/register/craft references only when materially relevant and actually available. If a required specialized reference is not packaged or evidence is insufficient, HOLD instead of inferring a rule from memory.

For creative output, keep evaluation on the technical backplane unless TRACE is explicitly requested. Evaluation must not leak into art.
